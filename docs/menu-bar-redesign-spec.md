# Magpie-WebUI-Tunnel 菜单栏改版规格

设计已确认，实现已完成（见文末「实现状态」）。

改版覆盖整个菜单栏弹窗，以及原先交由其他应用处理的隧道配置和日志。界面使用简短的状态与操作标签，只有需要说明后果、错误原因或下一步时才增加正文。应用保持 macOS 原生风格，通过对齐、间距、分组和字号体现主次，颜色主要用于表达状态。

## 菜单栏面板

- 点击菜单栏图标打开紧凑面板。顶部显示连接概况，中间按配置顺序显示各隧道的名称、连接状态和本地端口，底部提供「隧道配置」「隧道日志」入口与「退出」按钮。
- 每行直接提供「打开 Magpie」和「复制链接」，仅在隧道已连接时可用。Web 密钥无需在面板上明文显示。
- 自动刷新状态。已知异常时，显示简短的原因，并可通过日志查看详细信息。只有确认在建立连接时才显示「连接中」。没有可信状态时显示「状态未知」，包括启动后还未收到有效状态的情况。已知文件配置错误应与连接断开区分。
- 无配置目标时显示「尚未配置隧道」及「添加隧道」。点击后进入配置窗口的新建表单。
- 面板右上角提供「重启全部隧道」图标按钮（无隧道或配置损坏/不可读时禁用），重启前确认并说明现有连接会短暂中断；右下角提供「退出」按钮（默认常规文字颜色，悬停时变为红色），沿用现有的退出确认对话框。
- 配置和日志各自使用一个应用内窗口，可同时打开。重复点击入口时将对应窗口带到前台。应用保持纯菜单栏模式。

## 隧道配置窗口

- 左侧列表选择隧道，表单分别编辑名称、本地端口、SSH 目标、远端端口和 Web 密钥。支持新增、修改和删除。Web 密钥默认遮挡，可主动显示及编辑，可以留空。
- 修改留在草稿中。保存前可撤销删除，提交时列出待删除的隧道供用户确认。关闭有未保存改动的配置窗口时，允许保存、放弃更改或取消关闭。
- 单次「保存并应用」校验全部草稿，在相关字段显示错误，并一次写入有效变更。使用现有配置格式和校验规则，保留原有注释及空行。已有错误行须显示行号与原因，并支持在窗口内修正或明确移除。
- 如外部修改了配置文件，保留窗口中的草稿并阻止覆盖，提示文件已变化并提供重新载入操作。移除最后一条隧道后，保存无目标的配置，避免回退到内置目标。
- 写入后立即请求守护进程重读。新增项启动，删除项停止，改变的连接按需重连，未变的连接继续运行。收到本次配置的应用确认后显示「已应用」，各隧道的连通性由面板状态独立反映。若写入成功但未收到应用确认，显示「配置已保存，尚未确认应用」，并提供日志入口。写入失败时保留草稿并给出错误。

## 隧道日志窗口

- 默认显示「应用日志」，可用下拉菜单切换到单条隧道的 SSH 日志。
- 打开时定位最新输出并实时跟随。向上滚动会暂停自动滚动，点击「跳到最新」可恢复。支持搜索已加载的内容，以及选中并复制文本。
- 日志轮转后继续读取新的输出。已经加载的内容继续可搜索和复制。

## 应用与守护进程生命周期

- 关闭配置或日志窗口后，应用继续在菜单栏运行，隧道继续服务。
- 「退出」结束应用、守护进程和所有隧道。应用崩溃或被强制退出时，也须清理守护及 SSH 子进程。重新打开应用后按已保存配置启动隧道。
- 正常退出时，确认对话框说明所有隧道会断开。若配置有未保存的改动，在同一对话框提供「保存并退出」「放弃更改并退出」「取消」。「保存并退出」校验并保存供下次启动使用，保存失败时留在应用内以便修正。

## 命名与安装

- 对外严格使用 `Magpie-WebUI-Tunnel`，包括应用显示名、`Magpie-WebUI-Tunnel.app`、README 和发布包 `Magpie-WebUI-Tunnel-<版本>.zip`。窗口和命令中的应用名使用同一拼写。
- 安装说明要求先结束旧版应用及其仍在运行的守护进程，手动卸载旧版 `.app` 后再安装新版。安装流程无需探测或迁移旧应用。
- 沿用现有 bundle ID、配置与日志路径，以便装上新版后继续使用原有数据。保留现有 macOS 最低版本和公开的隧道配置、链接格式。

## 验收

- 在隔离目录和模拟 SSH 下验证新增、修改、删除、外部编辑冲突、无配置目标、差量应用、确认超时，以及正常退出、强制退出和重新启动。验证保存与应用结果可独立辨认，未修改隧道保持连接，退出后无遗留守护或 SSH 子进程。
- 在 macOS 上检查菜单栏面板、窗口复用和并行打开、异常与未知状态、日志实时追加和轮转，以及重启与退出确认。检查浅色和深色界面中状态和操作均可辨认。
- 运行 `swift test` 和应用构建。检查发布文件名、应用名称元数据、bundle ID 以及安装文档中的旧版卸载步骤。
